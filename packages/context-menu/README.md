# @pablo-v/context-menu

Right-click menu built on the menu primitives

```bash
pnpm add @pablo-v/context-menu @pablo-v/tokens
```

It reuses the styles of `@pablo-v/menu`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/menu/style.css';
import '@pablo-v/context-menu/style.css';
import { ContextMenu } from '@pablo-v/context-menu';
```
