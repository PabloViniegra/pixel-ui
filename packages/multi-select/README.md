# @pablo-v/multi-select

Combobox that picks several options shown as chips

```bash
pnpm add @pablo-v/multi-select @pablo-v/tokens
```

It reuses the Input box and the styles of `@pablo-v/input`, `@pablo-v/chip`, `@pablo-v/autocomplete`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/chip/style.css';
import '@pablo-v/autocomplete/style.css';
import '@pablo-v/multi-select/style.css';
import { MultiSelect } from '@pablo-v/multi-select';
```
