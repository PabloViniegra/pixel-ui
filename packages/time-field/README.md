# @pablo-v/time-field

Segmented time input and time picker

```bash
pnpm add @pablo-v/time-field @pablo-v/tokens
```

It reuses the styles of `@pablo-v/input`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/time-field/style.css';
import { TimeField } from '@pablo-v/time-field';
```
