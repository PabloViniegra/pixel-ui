# @pablo-v/number-field

Numeric input with stepper buttons and keyboard increments

```bash
pnpm add @pablo-v/number-field @pablo-v/tokens
```

It reuses the styles of `@pablo-v/input`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/number-field/style.css';
import { NumberField } from '@pablo-v/number-field';
```
