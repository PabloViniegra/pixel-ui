# @pablo-v/file-upload

Drag-and-drop file picker with a file list

```bash
pnpm add @pablo-v/file-upload @pablo-v/tokens
```

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/file-upload/style.css';
import { FileUpload } from '@pablo-v/file-upload';
```

Import `@pablo-v/pixel-icons/style.css` too if you want the drop icon to animate while a file is dragged over; without it the first frame shows.
