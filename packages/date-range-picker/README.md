# @pablo-v/date-range-picker

Start and end date fields with a pop-up range calendar

```bash
pnpm add @pablo-v/date-range-picker @pablo-v/tokens
```

It reuses the Input box and the styles of `@pablo-v/input`, `@pablo-v/calendar`, `@pablo-v/date-field`, `@pablo-v/date-picker`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/calendar/style.css';
import '@pablo-v/date-field/style.css';
import '@pablo-v/date-picker/style.css';
import '@pablo-v/date-range-picker/style.css';
import { DateRangePicker } from '@pablo-v/date-range-picker';
```
