# @pablo-v/date-picker

Date field with a pop-up calendar

```bash
pnpm add @pablo-v/date-picker @pablo-v/tokens
```

It reuses the Input box and the styles of `@pablo-v/input`, `@pablo-v/calendar`, `@pablo-v/date-field`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/calendar/style.css';
import '@pablo-v/date-field/style.css';
import '@pablo-v/date-picker/style.css';
import { DatePicker } from '@pablo-v/date-picker';
```
