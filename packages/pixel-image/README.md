# @pixel-ui/pixel-image

Image that loads as a coarse pixel mosaic and sharpens to full resolution

```bash
pnpm add @pixel-ui/pixel-image @pixel-ui/tokens
```

```tsx
import '@pixel-ui/tokens/styles.css';
import '@pixel-ui/pixel-image/style.css';
import { PixelImage } from '@pixel-ui/pixel-image';
```
