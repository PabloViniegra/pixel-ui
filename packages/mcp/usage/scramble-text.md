A signature moment: text that decodes from pixel glyphs. Use it on a hero headline, a key number or a label that just changed.

- At most one or two per view, on short strings. Never on body text, form labels or anything the user needs to read immediately.
- `trigger="inView"` for content below the fold, `hover` for links and nav items, `manual` with `play` to react to an event.
- Screen readers always get the final text, so it is safe for meaningful content.
