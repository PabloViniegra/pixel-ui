Use to divide groups of content or controls.

- Prefer spacing first; add a separator only when groups would otherwise blur together.
- `label` for an "or" divider between alternatives. `variant="pixel"` is decorative; use it sparingly.
- Set `decorative={false}` when it marks a real boundary between sections that assistive tech should announce.
- A vertical separator needs a parent with a defined height (for example a flex row).
