Use as the global ⌘K palette of an application: navigation targets and commands in one searchable list.

- Mount it once near the app root; ⌘K / Ctrl+K toggles it by default (`hotkey`). Add a visible `trigger` so it is discoverable without the shortcut.
- A menu of actions for one element: use `Dropdown`. Picking a form value: use `Autocomplete`.
- Give each command a `group`, and `keywords` for synonyms; show its real shortcut in `shortcut`.
- Every command must also be reachable through the regular UI.
