Use for several related sections where readers open only what they need: FAQs, settings groups, long detail pages.

- One standalone section: use `Collapsible`. Peer views where exactly one is always visible: use `Tabs`.
- `type="single"` when open sections would push each other off screen; keep the default `multiple` when users compare sections.
- Do not hide content most users need; an accordion is for secondary detail.
- Put short status or counts in `meta`, not in the title.
