# @pablo-v/search-input

Search field with a clear button

```bash
pnpm add @pablo-v/search-input @pablo-v/tokens
```

It reuses the Input box and the styles of `@pablo-v/input`; import that stylesheet before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/search-input/style.css';
import { SearchInput } from '@pablo-v/search-input';
```
