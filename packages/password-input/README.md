# @pablo-v/password-input

Password field with a show/hide toggle

```bash
pnpm add @pablo-v/password-input @pablo-v/tokens
```

It reuses the Input box and the styles of `@pablo-v/input`; import that stylesheet before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/password-input/style.css';
import { PasswordInput } from '@pablo-v/password-input';
```
