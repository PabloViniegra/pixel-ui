# @pablo-v/date-field

Segmented date input that follows the locale order

```bash
pnpm add @pablo-v/date-field @pablo-v/tokens
```

It reuses the Input box and the styles of `@pablo-v/input`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/date-field/style.css';
import { DateField } from '@pablo-v/date-field';
```
