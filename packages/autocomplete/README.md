# @pablo-v/autocomplete

Combobox that filters a list of options as you type

```bash
pnpm add @pablo-v/autocomplete @pablo-v/tokens
```

It reuses the Input box and the styles of `@pablo-v/input`; import those stylesheets before its own.

```tsx
import '@pablo-v/tokens/styles.css';
import '@pablo-v/input/style.css';
import '@pablo-v/autocomplete/style.css';
import { Autocomplete } from '@pablo-v/autocomplete';
```
