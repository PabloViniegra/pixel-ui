# Foundations

All tokens live in `@pixel-ui/tokens` as CSS custom properties prefixed with `--pxl-`.
Override any of them on `:root` or on a container to theme a section.

## Colour

Switch the theme from the toolbar to see light and dark values.

<ColorGrid />

## Typography

Geist (`--pxl-font-sans`) carries labels and body text, Geist Mono (`--pxl-font-mono`) carries numbers.
Geist Pixel is reserved for display and titles: five variants (SIL OFL 1.1), `--pxl-font-pixel`
defaults to **Square**.

## Spacing, shapes and elevation

`--pxl-unit` is **4px**. Spacing tokens (`--pxl-space-1…8`) are multiples of it.

Corners use `--pxl-radius-xs … lg` and `--pxl-radius-full`. Elevation is soft and only appears as
feedback: `--pxl-shadow-sm` and `--pxl-shadow-md` (both `none` in dark mode, where borders carry depth).
