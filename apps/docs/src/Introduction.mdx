Minimal React components with a Vercel feel: greyscale surfaces, one accent, soft shapes and
motion that is fast and springy. **Geist Pixel** type and a few 8-bit details are the signature.

## Principles

- **Soft by default.** Everything snaps to a 4px unit; corners are rounded and shadows are soft.
  Pixels are a signature, not a texture.
- **Motion with intent.** Springs and ease-out for movement, `steps()` only for the loader and text scramble. Respects
  `prefers-reduced-motion` automatically.
- **One package per component.** Every component is versioned, changelogged and published
  on its own — install only what you use.
- **Accessible by default.** Real roles, labels and keyboard support; checked with the a11y addon.

## Install

```bash
# just what you need…
pnpm add @pablo-v/tokens @pablo-v/button

# …or everything
pnpm add @pablo-v/react
```

```tsx
import '@pablo-v/tokens/styles.css';   // tokens, Geist Pixel @font-face, keyframes
import '@pablo-v/button/style.css';
import { Button } from '@pablo-v/button';

export function Deploy() {
  return <Button>Deploy</Button>;
}
```

### Next.js

If you already load Geist Pixel with `geist/font/pixel`, import `@pablo-v/tokens/tokens.css`
and `@pablo-v/tokens/motion.css` instead of `styles.css` — the tokens read the
`--font-geist-pixel-*` variables that `next/font` sets.
